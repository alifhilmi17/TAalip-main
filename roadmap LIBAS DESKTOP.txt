=======================================================
           ROADMAP PENGEMBANGAN LIBAS DESKTOP
                 (Sistem Offline-First)
=======================================================

Roadmap ini merangkum langkah-langkah yang diperlukan 
untuk mengubah aplikasi web LIBAS menjadi Aplikasi Desktop 
yang sepenuhnya mendukung fitur bekerja secara Offline.

-------------------------------------------------------
FASE 1: PERSIAPAN & PENYEMPURNAAN OFFLINE MODE
(Memastikan logika web siap untuk skenario tanpa internet)
-------------------------------------------------------
[ ] 1. Memastikan fitur Firebase Offline Persistence (IndexedDB) 
       tetap aktif di `firebase-init.js`.
[ ] 2. Memodifikasi `login-interactive.js` untuk fitur 
       "Auto-Login Bypass". Jika aplikasi dibuka offline dan
       masih ada token sesi, aplikasi akan melompati form
       login dan langsung masuk ke Dashboard.
[ ] 3. Menambahkan logic di tiap halaman dashboard untuk antrean
       (queueing) proses penyimpanan data jika internet mati,
       serta memunculkan notifikasi UI "Mode Offline Aktif".

-------------------------------------------------------
FASE 2: IMPLEMENTASI PWA (Progressive Web App)
(Langkah termudah menjadikannya aplikasi terinstal di PC)
-------------------------------------------------------
[ ] 1. Menyiapkan Aset Ikon Aplikasi: 
       Menyiapkan logo ayam LIBAS berukuran 192x192 px dan 
       512x512 px dalam format .png.
[ ] 2. Membuat file `manifest.json`:
       Berisi metadata aplikasi (nama, warna tema, ikon) agar
       browser mengenali LIBAS sebagai aplikasi mandiri.
[ ] 3. Menyematkan Manifest ke HTML:
       Menambahkan tag <link rel="manifest" href="/manifest.json"> 
       ke dalam tag <head> di semua file HTML (terutama login.html & index.html).
[ ] 4. Membuat Service Worker (`sw.js`):
       Script yang berjalan di background untuk men-download dan 
       menyimpan (cache) seluruh file HTML, CSS, JS, dan Gambar ke 
       memori komputer agar bisa dimuat saat internet mati total.
[ ] 5. Mendaftarkan Service Worker:
       Menambahkan script kecil di HTML untuk memanggil `sw.js`.
[ ] 6. Testing Instalasi:
       Membuka aplikasi di Chrome/Edge, menekan tombol "Install LIBAS", 
       lalu mencoba mematikan internet dan membuka aplikasi lewat 
       shortcut di Desktop.

-------------------------------------------------------
FASE 3: IMPLEMENTASI ELECTRON.JS (OPSIONAL)
(Hanya jika Anda benar-benar butuh file installer .exe)
-------------------------------------------------------
[ ] 1. Install NodeJS di komputer pengembang.
[ ] 2. Inisialisasi npm (`npm init`) di folder proyek.
[ ] 3. Install framework Electron (`npm install electron --save-dev`).
[ ] 4. Membuat file `main.js`:
       Script khusus untuk mengatur ukuran jendela Desktop, menu bar, 
       dan menyambungkannya dengan `login.html`.
[ ] 5. Penyesuaian Path:
       Memastikan semua link `<a href="...">` dan `<script src="...">` 
       berjalan normal di lingkungan desktop (path relatif).
[ ] 6. Packaging & Distribusi:
       Menggunakan library `electron-builder` untuk mengemas aplikasi 
       menjadi satu file installer utuh (`LIBAS-Setup.exe`).

=======================================================
Saran Tindakan Selanjutnya:
- Mulai dari FASE 1 poin 2 (Modifikasi Bypass Login) terlebih dahulu.
- Setelah itu, FASE 2 adalah langkah yang sangat disarankan untuk
  langsung mendapatkan hasil instan berwujud Aplikasi Desktop.
