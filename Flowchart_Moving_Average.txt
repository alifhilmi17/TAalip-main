================================================================================
                        PENJELASAN ALGORITMA
================================================================================

1. KONSEP MOVING AVERAGE (MA):
   Moving Average adalah metode peramalan yang menghitung rata-rata dari N data
   terakhir untuk memprediksi nilai periode berikutnya.
   
   Rumus: MA(t+1) = (X(t) + X(t-1) + X(t-2) + ... + X(t-N+1)) ÷ N
   
   Dimana:
   - MA(t+1) = Prediksi untuk periode berikutnya
   - X(t)    = Data aktual periode saat ini
   - N       = Jumlah periode yang digunakan (window size)

2. CONTOH PERHITUNGAN (Periode MA = 3 Hari):
   
   Data Historis Produksi (Butir):
   H-2: 100 butir → 6.25 Kg
   H-1: 110 butir → 6.88 Kg
   H-0: 120 butir → 7.50 Kg (Hari Ini)
   
   Kalkulasi MA:
   sumKg = 6.25 + 6.88 + 7.50 = 20.63 Kg
   prediksiBesokKg = 20.63 ÷ 3 = 6.88 Kg
   prediksiBesokButir = 6.88 × 16 = 110 butir
   
   Hasil: Prediksi produksi besok adalah 110 butir telur.

3. MOVING WINDOW (Proyeksi 7 Hari):
   Untuk proyeksi multi-hari, hasil prediksi hari sebelumnya dimasukkan
   ke dalam history untuk menghitung prediksi hari berikutnya.
   
   Contoh (MA-3):
   History awal: [6.25, 6.88, 7.50]
   
   H+1: (6.25 + 6.88 + 7.50) ÷ 3 = 6.88 Kg
   History update: [6.88, 7.50, 6.88]
   
   H+2: (6.88 + 7.50 + 6.88) ÷ 3 = 7.09 Kg
   History update: [7.50, 6.88, 7.09]
   
   H+3: (7.50 + 6.88 + 7.09) ÷ 3 = 7.16 Kg
   ... dan seterusnya hingga H+7

4. VALIDASI DATA INTEGRITY:
   - Total telur tidak boleh melebihi jumlah ayam (1 ayam = max 1 telur/hari)
   - Periode MA harus ≤ jumlah data historis yang tersedia
   - Semua data wajib (H-0 s.d H-(N-1)) harus terisi lengkap
   - Populasi ayam harus > 0

5. REKOMENDASI PREDIKTIF:
   Sistem menganalisis hasil prediksi dan memberikan rekomendasi berdasarkan:
   - Status finansial (untung/rugi/margin tipis)
   - Kinerja produksi (HDP - Hen Day Production)
   - Tren produksi (naik/turun/stabil)
   - Efisiensi pakan (FCR - Feed Conversion Ratio)
   - Proyeksi 7 hari ke depan (berapa hari rugi/untung)

================================================================================
                        KEUNGGULAN ALGORITMA MA
================================================================================

✅ KELEBIHAN:
   • Sederhana dan mudah dipahami
   • Cocok untuk data dengan pola stabil/konsisten
   • Mengurangi noise/fluktuasi acak dalam data
   • Responsif terhadap perubahan tren (terutama MA periode pendek)
   • Tidak memerlukan data historis yang sangat panjang

⚠️ KETERBATASAN:
   • Kurang akurat untuk data dengan tren kuat atau musiman
   • Lag (keterlambatan) dalam mendeteksi perubahan tren mendadak
   • Semua data historis diberi bobot yang sama (tidak ada prioritas)
   • Tidak memperhitungkan faktor eksternal (cuaca, penyakit, dll)

💡 REKOMENDASI PENGGUNAAN:
   • MA-3: Untuk deteksi perubahan cepat, responsif terhadap fluktuasi harian
   • MA-5: Standar, keseimbangan antara responsif dan stabilitas
   • MA-7: Untuk tren jangka panjang, lebih halus dan stabil

================================================================================
                        INTEGRASI DENGAN SISTEM
================================================================================

1. DATA SOURCE:
   • Batch Ayam: Firestore collection "populasi_ayam"
   • Data Produksi: Firestore collection "produksi_harian"
   • History Prediksi: Firestore collection "prediksi_history"

2. AUTO-FILL FEATURE:
   • Sistem otomatis memuat data produksi dari batch yang dipilih
   • Filter berdasarkan batchId dan ambil N data terakhir
   • Isi otomatis ke form input historis produksi
   • Validasi jika data kurang dari periode MA yang dipilih

3. REAL-TIME SYNC:
   • Data batch dan produksi di-sync real-time via Firestore onSnapshot
   • Perubahan data langsung terlihat tanpa refresh halaman
   • History prediksi tersimpan untuk analisis tren jangka panjang
